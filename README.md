# Forensic Accounting Dashboard

## Project Overview
An interactive forensic accounting dashboard developed using Microsoft Power BI to analyse financial transactions, identify potential anomalies, and support risk-based investigation.

## Dashboard Pages
- **Executive Risk Overview:** Summarises transaction volume, total recorded amount, high-risk transactions, flagged transactions, monthly trends, and department/account-level transaction values.
- **Transaction Investigation:** Examines transaction anomalies, risk scores, vendor/customer activity, and suspicious transaction records.

## Tools Used
- Microsoft Power BI
- Power Query and DAX
- Excel

## Key Findings
- Total transactions analysed: 200
- Total recorded amount: ₹18,46,037
- High-risk transactions: 11
- Flagged transactions: 25

*Flagged transactions indicate potential anomalies requiring further investigation; they do not independently establish fraud.*
